# Story Meta

Structure rules and templates for universe repos, so every story and `meta/` folder parses the same way — and the static-site generator turns any universe repo into a themed site by swapping CSS, not parsers.

- **[STRUCTURE.md](STRUCTURE.md)** — the layout, routing rules, frontmatter schema, and content conventions.
- **[templates/](templates/)** — starting files for a new universe repo, story, and `meta/` folder.
- **[site/](site/)** — the Astro static-site generator: point it at a universe repo, pick a theme, get a site.
