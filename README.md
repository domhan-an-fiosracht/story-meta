# story-meta

Structure rules and templates for universe repos, so every story and `meta/` folder parses the same way — and a future static-site generator can turn any universe repo into a themed site by swapping CSS, not parsers.

- **[STRUCTURE.md](STRUCTURE.md)** — the layout, routing rules, frontmatter schema, and content conventions.
- **[templates/](templates/)** — starting files for a new universe repo, story, and `meta/` folder.

## Universes

Every universe repo under [domhan-an-fiosracht](https://github.com/domhan-an-fiosracht).

| Universe | Tagline | Description |
|---|---|---|
| [Porchlight](https://github.com/domhan-an-fiosracht/porchlight) | The lights went out. Somebody has to turn them back on. | Cryptids lived quietly inside human cities until a zombie virus broke the masquerade at its ugliest — humanity's first look at them was infected werewolves rampaging on phone footage. | [The Good Neighbors](https://github.com/domhan-an-fiosracht/the-good-neighbors) | Humanity was never alone. First contact means meeting both. |
| [Undercurrent](https://github.com/domhan-an-fiosracht/undercurrent) | Magic was never hidden, only the people using it. | Magic is a force of physics that anyone could learn, and cryptids are built around it.
